| 区域 | 现行值 | GitHub | 状态 |

### 1.2 内容区宽度【实测】

- 内容最大宽 **1200**，居中；左右 padding 16。
- 表格不得超出内容宽；任何宽度下**不出横向滚动**。

## 2. 通用组件规格（13 页共用）

### 2.1 搜索行【实测：GitHub issues 1047×30，我们 1088×32】

```
┌──────────────────────────────────────────────────────────────┬────┐
│ 搜索或筛选：主题:T1、文号:金非银检函…（回车应用）              │ 🔍 │
└──────────────────────────────────────────────────────────────┴────┘
```

| 属性 | 规格 |
|---|---|
| 位置 | 列表上方**独占一行**，宽度 = 内容宽（不与表格同一外框） |
| 高 | 30（GitHub）/ 32（现行，差 2） |
| 图标区 | 右侧独立 28×28、底色 `#f6f8fa`、左侧 1px 分隔线、圆角 `0 6 6 0` |
| 聚焦 | **单层** `outline: 2px solid #0969da`，无 shadow 叠加 |
| 行为 | 输入即筛（前端）+ 回车应用（服务端 token 查询）；两者取**交集**，筛选后搜索词保留 |

### 2.2 工具条【实测：左状态 / 右筛选】

```
[待处置 319] [已处置 10]        …剩余空间…        [筛选 ▾ ▾]  [≡ ☰]
└──── 左：状态开关 ────┘                        └─ 右：筛选按钮 + 密度 ─┘
```

| 属性 | 规格 |
|---|---|
| 高 | 自适应（48 起），允许换行 |
| 分组 | flex：左组 `order:1`；`.sp{flex:1}` 占位；右组 `order:4/5` |
| 溢出 | `wrap`，**不得裁切**（历史 bug：`nowrap+hidden` 裁掉按钮） |

### 2.3 表格【实测】

| 项 | 规格 |
|---|---|
| 外框 | **无**（`table` / `scroll` 均 0px） |
| 表头 | 上 1px + 下 1px `#d1d9e0`，无底色 |
| 行 | 每行 1px 底边，末行 0 |
| 行高 | 32（列表页）/ 34（带行内按钮） |
| 列宽 | 弹性算法：短列 clamp(need+24, 64, 220)；长列按权重；极端串固定 200 且不参与权重；总宽 ≤1200 |
| 末列 | 动作列保底 72（图标组 148），不得撑出边框 |

### 2.4 分页【实测：表格外】

```
                    [上一页]  1 / 332  [下一页]
```

- 位置：**表格容器之外**，下方 16px；
- GitHub 形态为页码按钮组 + 每页条数，我们是简化版（差异登记）。

### 2.5 按钮【实测：宽度 = 文字 + 24 + 2】

| 属性 | 规格 |
|---|---|
| 高 | 32（行内 24/28） |
| padding | `0 12px`；`min-width: 0`（禁止 88px 硬撑） |
| 圆角/边框 | 6px / 1px `#d1d9e0` |
| 主按钮 | 绿底白字（GitHub `btn-primary`） |

### 2.6 筛选面板【实测】

| 属性 | 规格 |
|---|---|
| 宽 | 320；行高 32；内边距 8 |
| 边框/圆角 | 0 + 环阴影；圆角 12 |
| 单选 | **无勾选框**，选中行底色 `.15`，hover `.1` |
| 多选 | 有勾选框（Label 面板） |
| 面板内搜索 | 高 30，放大镜在**左** |

### 2.7 表单【实测：advisories/new，控件 878×32】

```
处置理由                        ← label 在上、600 字重、下方 6px
┌────────────────────────────┐
│                            │  ← 控件满宽（= 容器 − 32）
└────────────────────────────┘
                        [取消] [提交]
```

| 项 | 规格 |
|---|---|
| label | 块级、12px、600、下方 6px |
| 控件 | 满宽、高 32；文本域 100 |
| 必填 | label 后加 `*`，提交前校验并定位 |
| 按钮区 | 右对齐，取消在左、主按钮在右 |

### 2.8 卡片与图表【实测】

- 栅格 3 列，gap 16；卡片 `border 1px #d1d9e0`、`radius 6`、`padding 16`；
- 图表高 220（通栏 220/300）；断点：≤1011 两列、≤767 单列。

### 2.9 空态 / 错误态 / 加载态（**当前 13 页全缺**）

| 态 | 规格 |
|---|---|
| 加载 | 骨架行 ×5，或 `加载中…` 占位（保持容器高度） |
| 空 | 居中图标 + 一句说明 + 一个主操作（如「清除筛选」） |
| 错误 | 红字说明 + 重试按钮 + 错误码（不吞异常） |

## 3. 逐页规格

> 每页结构：**功能清单（实测自旧版 DOM/源码）** → **设计图** → **与 GitHub 的差异**。

### 3.1 总览 `overview` ↔ contributors

**功能清单**

| 区块 | 内容 | 数据 |
|---|---|---|
| KPI 行 | 门禁通过 x/y · 待办未处置 · 链步成功 · 步失败 · 存储占用 | `/api/overview` |
| 运行健康 | 状态分布、累计耗时、最近运行、最近一轮、通过数 | 同上 `run_health` |
| 门禁与待办 | 通过/失败明细、open 总数、最老未处置、按 kind 跳转待办 | 同上 `gate_status`/`worklist` |
| 数据新鲜度 | 边状态、发布件状态、双底座、条文契约自检、覆盖文件数 | 同上 `freshness` |
| 存储 | 总容量、占用比例（raw/cleaned/clauses/governance_db/external_models） | 同上 `storage` |
| 告警 | 无告警时的说明文案、有告警时的条目 | 同上 `alerts` |

**设计图**

```
┌───────────────────────────────────────────────────────────────┐
│ 关键指标                             最近运行 2026-11-05 06:44 │ 通栏
│ [门禁通过 29/31] [待办 319] [链步成功 35] [存储 4.2 GB]        │
├───────────────┬───────────────┬───────────────────────────────┤
│ 运行健康       │ 链步状态分布   │ 门禁与待办                    │ 3 列 gap16
│ 状态分布 …     │ (环形图)       │ 失败明细 …                    │
├───────────────┼───────────────┼───────────────────────────────┤
│ 数据新鲜度     │ 存储           │ 告警                          │
└───────────────┴───────────────┴───────────────────────────────┘
```

**GitHub 差异**：contributors 是「1 通栏 + 2 列」；我们按 D1 决议用 **3 列**（有意偏离，登记在案）。
缺：Period 时间窗（后端无序列）、图表图例交互。

**功能清单**

### 3.3 数据流转 `flow` ↔ Actions

**功能清单**

| 项 | 说明 | 数据 |
|---|---|---|


### 3.11 文档检索 `search`

**功能清单**

| 控件 | 说明 |
|---|---|
| 检索类型 | **记录** / **条文**（两套检索目标） |
| 检索按钮 / 回车 | 提交查询 |
| 模式提示 | 模糊匹配（短词） / 全文索引（≥3 字） |
| 结果列 | 唯一标识号 · 标题 · 文号 · 时效 · 访问地址 |
| 空态 | 「无命中（换个关键词，或确认底座已发布）」 |

**数据**：`/api/search`（`mode`/`backend`/`note` 字段说明当前模式）；本地文件 `/api/local/file`。

**差距**：新版**只做了「记录」**，没有「条文」检索切换。

### 3.12 发布事件 `release` ↔ commits

**差距**：新版只有 sha/主题/日期三列，**缺作者、按日期分组、变更统计、sha 复制**。

## 5. 功能丢失对照（新版 vs 旧版）

| 页 | 旧版功能数（控件计） | 新版已实现 | 丢失 |
|---|---|---|---|
| 总览 | 6 区块 + 6 KPI | 6 区块 | 告警条目、按 kind 跳转 |
| 项目结构 | 树 + 节点信息 | 树 | 节点信息栏 |
| 数据流转 | 桑基 + 13 链 + 未连线表 | 桑基 | 13 链分组、未连线表 |
| 指标 | 6 图 + 1 开关 | 5 图 | DAMA 六维、质量快照、趋势开关 |
| 待办 | 状态/kind/搜索/行内/批量/全选 | 状态/kind/搜索/行内/批量 | 全选、详情、复制 |
| 政策法规 | 搜索语法/排序/筛选/视图/关系/复制/导出 | 搜索/排序 | 视图、关系跳转、复制、导出、批量理由 |
| 公司制度 | 同上 | 同上 | 同上 |
| 关系图谱 | 全局 + 单文件双视图 | 四视图 | 单文件跳转、截断提示 |
| 监管统计 | **7 分区** | 1 分区 | **6 个分区** |
| 治理审计 | 运行 + 审计双表 | 双表 | 状态筛选 |
| 文档检索 | 记录/条文 双类型 | 记录 | **条文检索** |
| 发布事件 | 提交 + 变更 + 发布件 + 认证 | 三列 | 变更、分组、认证卡 |
| 留言板 | 表单 + 列表 + 处置 | 列表 | **表单、处置、状态** |

**结论：新版的"功能缺失大半"是事实**，集中在：监管统计 6 分区、留言板表单/处置、文档检索条文、发布事件变更、政策法规的 4 个操作。
