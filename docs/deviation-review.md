# 实现 vs 规格偏差检视（2026-11-06）

> 对照基准：`docs/spec-github-replica.md` v10.2
> 检视方式：脚本对 `web/assets/app.html` + 13 个页面 + `js/ui/*.js` 做静态取证（导航项、壳尺寸、`.filter/.sort` 调用、关键字存在性），不凭记忆。
> 结论：**13 页都能跑，但与规格仍有 10 处偏差**，其中 3 处是结构性的（导航、数据边界、壳尺寸），不是样式细节。

## 三、根因

1. **规格是"目标态"，实现是"逐页搬迁"**：我把 13 个旧页逐个换渲染，**没有先做一次导航与侧栏的信息架构重构**（D1），于是规格里"合并菜单/业务切片"从未进入代码。
2. **§8.9 是我自己写的约束，但没进门槛**：没有任何断言禁止 `.filter/.sort`，所以写页面时顺手就用了（D2）。
3. **功能项（D3/D4/D5）都卡在同一个原因**：接口没有对应数据（条款、EAST 条目），我选择"先不画"，但没有把它们标成"未完成"进入清单，直到你追问（D3/D5 在报告里被记成了"遗留"，不是"未做"）。

---

## 四、修复顺序建议（按结构优先）

```
第 1 步（结构，半天）：D1 导航 8 项 + 侧栏业务切片 + D8 壳尺寸三处
第 2 步（边界，需后端）：D2 前端过滤 → 后端筛选/分页（E3），同时补门槛断言禁止 .filter/.sort
第 3 步（功能，纯前端）：D3 三图标（数字先取 relation/article 计数）+ D10 密度进 URL + D7 三条联动
第 4 步（后端依赖）：D4 条款页（E1）、D5 四分区（E5）
第 5 步（收口）：D6 模块拆分、D9 路由接线
```

**验收口径（写进门槛，避免再漂）**：
- 导航项数 = 8，且与 §4.2 表逐字一致；
- 页面内 `.filter/.sort` 计数 = 0；
- 壳三个尺寸与 §4.4 实测值误差 ≤2px；
- 三图标/条款页缺失时，页面必须显示"未接入 + 原因"，不能静默消失。
