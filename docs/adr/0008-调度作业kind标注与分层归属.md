# ADR-0008 调度作业 kind 标注与分层归属

- **状态**：已采纳（W1，2026-10-13；对应方案 §3.5 / E-3）
- **动因**：`config/schedule.yaml` 的作业与 STEP_LAYERS 的层之间无机器化关联——
  「这个定时作业跑的是链上哪一段」只能人读；`kind=event` 作业的承接步骤若不存在，
  作业永不触发且无门禁可发现（批 63 实证：event 作业全仓无分发器）。

## 决策

1. schedule.yaml 作业显式标注 `kind`（processing/quality/governance/agent_sync）与
   **分层归属**（expect_layers，对应 STEP_LAYERS 层键）；
2. `kind=event + after:` 的作业必须声明 `covered_by`（∈ STEP_ORDER 的真实步骤），
   由新门禁 `gate_declaration_executor`（E1）与 `gate_condition_observers`（T4）断言；
3. 作业与步骤的归属一致性由判据 R4/E3 机器校验（不靠人工对表）。

## 后果

- 调度声明面失实（声明先进、执行面缺失）有门禁兜底：event 无承接 / 告警无发送方 /
  resume 不可达 / manifest 无归属，四类全部阻断；
- 多体系频度调度（月度全链 / 周度增量 / 事件触发）的作业-层映射可机器读取。
