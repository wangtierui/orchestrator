# ADR-0003 P1 语义增强取值口径（analysis_view / 无度量不上线）

- **状态**：已采纳（N-171 / N-177）
- **动因**：`bge_base_zh`/`text2vec`/`youtu_embedding` 权重与依赖早已就绪
  （external/models 预置、preflight 五道闸全过），但主链无调用点——「模型就绪却未入链」；
  且 MODEL_BINDINGS 曾把它们绑在并无嵌入调用点的节点上（纸面接线）。

## 决策

1. **语义增强是旁路分析层，不是事实源**：产物 `reports/semantic/semantic_assist_*.{json,md}`
   只做主题最近邻裁定等**分析视图**，绝不写 cleaned/relations 等事实源；
2. **无度量不上线**：凡度量口径未定义的增强（阈值/采纳率），一律留空待度量，
   不臆造精确约束（版本区间为保守下界，首次实装冒烟后按实测锁定）；
3. **零硬依赖 + 降级链可观测**：`semantic` extra 可选；未启用或嵌入链不可用均为
   合法状态（工具显式披露且 rc=0），由 `usage_policy` + `semantic:preflight` 决定；
4. 入链步骤 `semantic:assist` / `docreader:extract` 均为**非阻断**增强层
   （STEP_LAYERS kind=enhancement）。

## 后果

- 判据 U（gate_config_integrity）：P1 语义工具清单自洽（零硬依赖/降级链/指纹三条
  纪律机器化）；
- docreader（WeKnora）以跨解释器子process 形态接入，产物同为分析视图；
- 增强层结论未经度量前不得进交付口径（延续到 W3 映射的 semantic 方法：待 P/R）。
