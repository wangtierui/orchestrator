# ADR-0004 分句 SSOT 收敛（sentence_boundary）

- **状态**：已采纳（N-90，第十六批）
- **动因**：句读集合与切分逻辑在多模块各自实现，口径漂移无门禁可发现。

## 决策

`std_lib/common_lib/sentence_boundary.py` 为句读集合**唯一定义处**：两级受控集合 +
共享切分器；清洗规则注册表（26 条/7 模块）与 contract/enums 分工写明，零注入加载。
零回归证据 = 样例 6/6 + 真实文本 84 条 **0 差异**后才切换。

## 后果

- 分句口径变化现在有单点可改、有回归可跑；
- 「先铸尺、后增强」纪律的组成部分：评测基线折叠进既有 `gen_benchmark`
  （`BENCHMARK.md §6` + `reports/评测基线_<date>.json`，可逐键 diff），
  不新建独立基线工具（避免顶破注入基线）。
