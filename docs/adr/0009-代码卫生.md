# ADR-0009 代码卫生（死代码退役 / 重复原语 SSOT / import 面基线冻结）

- **状态**：已采纳（W4，2026-10；对应方案第 7 章）
- **动因**：长期只做增量开发，代码层积累大量无效、冗余、废弃代码（两轮审查实证：
  37 个零引用脚本、HTTP 三套并存、6 类公共原语重复、幽灵注册点、双事实源、
  千行级大文件与死分支）。

## 决策（四条总原则）

1. **删除优先于保留**：无法证明有用的退役而非囤积——`tools/retired/` + 判据 J3
   （零引用断言）提供安全退役范式；
2. **一切清理以门禁化收口**：防复发比一次清干净更重要
   （`gate_no_duplicate_libs` 扫描模式扩展 `def _?(norm_title|normalize_date|
   sha256_of|write_jsonl)` 堵私有名绕过 + 同名函数实现体相似度检测 difflib>0.8
   告警不判死；`gate_import_bootstrap` import 面基线只减不增）；
3. **破坏面动作保留人工闸门**：删轨/删模块不自动执行；
4. **每项清理配回归测试**：清错了的代价 > 清不动的代价。

**重复原语 SSOT 收敛清单**：sha256（`io_atomic.sha256_bytes`）、normalize_date
（`norm.py` 分层：cleaner 唯一实现 + 豁免表）、norm_docno（`norm.py`，先对等测试
锁定 NULL_TOKENS/括号行为再删本地）、write_jsonl（`base_publish` 包级唯一实现）、
atomic_write（`fs_lock.atomic_write_text`）。

**大文件包化范式**：千行级单文件按职责拆包（governance_store 1507 行、
relations 1081 行、gate_config_integrity 1407 行）——**包 + 门面，import 路径不变**；
共用件住独立 `_common/_db` 子模块，禁止子模块回头 import 门面（环状导入运行期可解
但 mypy `[has-type]` 阻断）；契约测试冻结 import 面（`tests/test_import_surface.py`）。

## 后果

- T7 死代码 28 项清理（逐条 AST 校验）；5 个游离脚本标注特殊工具；
- HTTP 三套并存收敛为**单栈**：`http.py`（urllib `AdaptiveHttpClient`）为无会话 GET
  唯一实现，`crawler_common.robust_get` 实现并入、crawler_common 改 re-export 门面，
  `common/ratelimit.py` 退役（退避公式 SSOT 落 http.py）；`gov_collector.RobustSession`
  （requests Session + 连接池 + POST）分层保留——urllib 无连接复用对应能力，
  gov 千页级采集改 urllib 是性能退化。默认参数逐项对齐 + 两处加固向差异
  （UA 池 8 条 / decode_bytes）由对等测试锁定；
  ⚠️ **方向校正**：方案 §6.1 原文为「robust_get 为唯一出口、http.py 退役」，
  实作取反——「移动 + 适配，不重写」纪律下小面是吸收 robust_get（约 60 行）
  而非搬迁 http.py 的 382 行差异化能力（UA 轮换/冷却/代理池/流式 + 自检）。
- 「拆分类门禁的环状导入」成为可复用教训：子模块一律从 `_common` 取共用件。
