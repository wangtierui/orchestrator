# ADR-0001 raw 主库 JSONL 化

- **状态**：已采纳（批 47，a02be4d）
- **动因**：gov 主库 `.json`（458MB 单文件数组）全量载入使 clean 侧峰值 5.24~6.13GB；
  流式化改造的前提是格式本身可逐行读。

## 决策

五源 raw 主库 `.json → .jsonl`（首行 `_meta` 信封 + 一行一记录）。**迁移必须过
三步等价性证明**（缺一不可）：① 记录数一致；② 逐条规范化序列化的滚动 sha256 一致
（`json.dumps(rec, ensure_ascii=False, sort_keys=True)`）；③ 信封/元数据字段保留。
只有 ①②③ 全过才删除旧文件；迁移后做幂等验证（同一数据再跑一次写路径，sha 不变）。
gov：13178 条 / `f784c6e8…` 逐条一致后删旧；mof/nfra/pbc/supp 同法（870/1939/571/60）。

## 后果

- clean 侧改流式载入后 gov clean 峰值 5.24~6.13GB → 2.88GB；
- 「三步等价性证明」成为本仓数据格式迁移的**标准范式**（后续所有迁移沿用）；
- JSONL 化后读取侧须流式（`_count_jsonl` 按首字节嗅探分流，禁整文件载入）。
