| **口令** | **仅经 env `PGVECTOR_DSN`**（用户级环境变量）；仓库内**零凭据**（`gate_secret_scan` 守护） |
| **读写权限** | 专用 schema **`vec`**（业务向量数据与治理数据隔离）；role 有 `vec` 的 USAGE/CREATE/CRUD + `vector` 类型 USAGE；**对 `public` 无 CREATE**；`ROLSUPER=False` |

**权限自检（声明式断言 + 独立事务）**：`vec` USAGE/CREATE ✓、`public` **无 CREATE** ✓、`vector` 类型 ✓、
`rolsuper=False` ✓；**以 app role 实测**建表/写入/检索/HNSW 索引/清表 **5/5** ✓。

### P2 · 接入业务代码（**零侵入 + 降级链**）

- **位置**：`std_lib/common_lib/vector_store.py` —— `*_store` 家族（与 `governance_store`/`index_store` 同级），
  **符合既有分层**（模块经 `interfaces.*` 或 `std_lib` 访问，不新增跨模块直连）。
- **调用方式**：`ensure_table` / `upsert` / `search` / `search_or_fallback` / `health`；CLI `--health`。
- **数据读写路径**：写 `vec.<table>(doc_id text PK, emb vector(dim))`（**幂等 upsert**）；
  读 `ORDER BY emb <-> %s::vector`（L2）/ `<=>`（余弦）。表名走**白名单正则**（防标识符注入）。
- **异常处理**：统一 `VectorStoreUnavailable`（依赖缺失/无 DSN/连接失败/扩展缺失）；
  `search_or_fallback()` **失败返回 `None` 而不抛**（调用方据此走既有全文路径）；
  `fallback_hint()` 使**回退可观测**。
- **不影响主链**：主链（`cli.py run`）**不调用**其读写；仅 `pg:health` 做只读披露。
- **端到端验证**：L2 距离 `0.0 / 0.1414 / 1.4142`（**精确**）；余弦 `0.0 / 0.0061 / 1.0`；
  幂等 upsert ✓；无 DSN → 降级 `sqlite_vec` 且 `search_or_fallback` 返回 `None` ✓；表名注入 4/4 拦截 ✓。

### P3 · 全链数据流总图（**机器派生，非手写**）

`tools/gen_flow_map.py` 从**既有事实源**派生并输出 `docs/全链数据流总图.md`（**标注"请勿手改"**）：
- **顺序** ← `STEP_ORDER`；**命令** ← 源码 `_run` 调用点（行式 + 有界截取）；
- **作用** ← `PURPOSE`（键与实装一致 + **前缀兜底** `clean:gov`→`clean`）；
- **降级/失败语义** ← 由调用形态派生（阻断 / 条件 / **只读披露恒 rc=0**）；
- **⚠️ 未取得模型权重的环节单独标记** ← 清单 `offline_env` 工具 → `hanlp` / `text2vec` / `youtu_embedding`
  三个工具独立成表，并明示**受影响环节**（`semantic:preflight.offline`）与**不受影响范围**
  （主链全部走确定性路径，不依赖任何权重）。

### P4 · 途中即时发现并修复（**4 处，全部由门禁/自检暴露**）

| # | 问题 | 修复 |
|---|---|---|
| 1 | **自检脚本证据缺陷**：同一事务前序失败**连锁中止** + 未打印真实错误 → 把**权限问题误报为失败**，又把"表不存在"误当"无权限" | 改为**独立事务 + 声明式权限断言**（`has_schema_privilege` 等），并打印真实消息 |
| 2 | `ALTER ROLE ... PASSWORD %s` **语法错误**（DDL 不允许占位符） | 改用 `psycopg.sql.Literal` 安全转义 |
| 3 | `psycopg` 把 `list[int]` 适配为 **`smallint[]`** → 与 `vector` 列类型不符 | 显式字面量 + **`%s::vector` 强转**（不依赖适配器注册，更稳） |
| 4 | **门禁 4 次拦截**：① `gate_secret_scan` 命中我注释中的 DSN 示例；② 再次命中自检字面量；③ `gate_import_bootstrap`（`tools/` 注入 21>19，我自写了两处 `sys.path.insert`）；④ `gate_config_integrity J1`（新工具未入 `tools/_manifest.json`） | ① 注释改占位词；② 自检改无凭据形态；③ **改用唯一引导点 `bootstrap`**（运行方式 `python -m tools.gen_flow_map`）；④ 登记入清单 |

> 值得强调：**四个门禁中三个是"我引入的新缺陷"** —— 这正是它们存在的意义。
> 尤其 ③ 违背了"不重复造轮子"（仓内已有 `bootstrap.py` 作为唯一引导点），已按纪律改正。

## 三、规范对齐

| 规范 | 落实 |
|---|---|
| 不重复造轮子 | 接入层复用 `*_store` 家族与 `pgvector` 生态；引导复用 `bootstrap`；总图复用 `STEP_ORDER`/源码/清单（零手写） |
| 脚本共享 | `vector_store` 同时供 CLI / 链内 `pg:health` / 业务调用；`gen_flow_map` 单一实现 |
| 唯一事实源 | DSN 唯一于 env `PGVECTOR_DSN`；链路顺序唯一于 `STEP_ORDER`；工具信息唯一于清单 |
| 数据一致性 | 总图**机器生成**并标注禁手改；权限用**声明式断言**而非"跑一遍看是否报错" |
| 统一调度 | `pg:health` 入链（只读披露）→ `STEP_ORDER`/判据 R/守卫测试三处同步 |
| 数据处理节点入链 | 新增节点为**只读披露**（不动数据），符合既有 `retention:plan` 口径 |
| 安全 | 口令**仅 env**；仓库零凭据（`git grep` 复核）；业务用**最小权限非超管**角色 |
