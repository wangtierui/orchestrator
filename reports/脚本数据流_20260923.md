## 第 0 章 全局架构与工程配置

### 0.1 设计原则

本项目为**脚本编排型工程**，无常驻服务、无 Web 框架。核心架构纪律：

- **单向依赖**：`scraper → classifier → internal_base → drafter → analysis`，跨模块仅经 `interfaces/` 访问
- **路径唯一**：`paths.py` 为全仓唯一路径解析入口，禁止硬编码盘符
- **枚举唯一**：`config/enums.py` 为受控枚举唯一源，任何模块禁止本地定义枚举字面量
- **契约唯一**：`interfaces/contract.py` 为程序可读契约，`config/schema/contract_manifest.json` 登记各契约的版本与定位
- **文件即事实源**：治理库（`governance.db`）为只读投影/旁路观测设施，不阻断主链

### 0.2 全链数据流总图

    ↓

    ↓
classify --all → 归属表 + 11 份明细表 + 底座 + clause_graph
    ↓
relations gen → relations_index.jsonl + cross_basis.jsonl + rfn_backlog.csv
    ↓
reconcile → rfn_clean_bridge.csv + drift state
    ↓
governance sync → governance.db 四表投影
    ↓
recall → 召回复核报告 + 边界案例清单
    ↓
internal merged → merged_view.json
    ↓
reports build → 全景分析报告 + 主题分类报告

    ↓

### 1.2 各采集器详情

**`gov_collector.py`** — 国务院行政法规库采集（xzfgk 子源）。会话复用 + 连接池；请求头 / UA 轮换；随机延时 + 指数退避重试；自动遍历分页；对每条目二次请求详情页。gov 此前完全不抓附件，现已接入 `gov_fetch_attachments`。

**`gov_parse.py`**（53 行）— 国务院页面解析。数据源仅保留 xzfgk；`flk`（国家法律法规数据库）正文原文存储于站内 OBS 外部不可达，已停止抓取并清理相关代码（2026-09-04）。依赖 `requests` + `beautifulsoup4` + `lxml`。

**`gov_zhengceku.py`** — 国务院政策库专用解析（zhengceku 子源，与 xzfgk 页面结构不同）。

**`mof_collector.py`**（271 行）— 财政部法规数据库采集。目标站点 `fgk.mof.gov.cn` 为 layui SPA，直接调用后端 REST 接口：列表 `POST {HOST}/dev/lawFile/list`、详情 `GET {HOST}/dev/lawFile/get/{id}`、附件 `GET {HOST}/file/f/get?infoId={id}&fileType=0/90`。增量 diff 更新（默认）：载入历史存储，仅对新增/变更条目抓详情，消失条目标记 `removed` 而非删除。依赖仅 Python 标准库。

**`mof_attachments.py`** — 财政部附件下载。魔数校验文件类型。

**`nfra_collector.py`**（357 行）— 金融监管总局采集。基于逆向前端 JS 得到的数据接口：列表 `GET {BASE}/cbircweb/DocInfo/SelectDocByItemIdAndChild`、详情 `GET {BASE}/cbircweb/DocInfo/SelectByDocId?docId={文档ID}`，返回 `docClob`（正文 HTML）、`documentNo`（发文字号）、`docSource`/`agencyTypeName`（发文机关）、`builddate`（成文日期）、`indexNo`（索引号）。依赖仅 Python 标准库 + lxml。默认请求间隔 1.5~3.0 秒；遇到连续失败主动退避。

**`nfra_weekly.py`** — nfra 周度增量链。列表顶部窗口刷新 → 详情续跑 → 离线重建。被 `run_production_refresh.py --collect nfra-weekly` 调用。

**`nfra_fetch_attachments.py` / `nfra_fetch_lists.py` / `nfra_fill_details.py` / `nfra_prefetch.py` / `nfra_seed_cache.py` / `nfra_validate_cache.py` / `nfra_attachments_extract.py`** — nfra 采集链的附件下载、列表抓取、详情补全、预取、种子缓存、缓存校验、附件文本抽取组件。

**`pbc_collector.py`**（329 行）— 人民银行采集。对四个栏目（国家法律 / 行政法规 / 部门规章 / 规范性文件）自动遍历静态分页。分页机制自适应：从列表页隐藏字段 `article_paging_list_hidden` 动态提取 `moduleid` 与 `totalpage`。两种条目类型全覆盖：HTML 详情页解析 + 附件下载。可断点续跑。缓存委托 `std_lib/scraper_std/cache_store`（2026-09-05）。

**`pbc_parse.py`** — pbc 页面解析。

**`pbc_merge_scrape.py` / `pbc_backfill_pdfs.py` / `pbc_fix_doc.py` / `pbc_recover.py` / `pbc_run_batched.py` / `pbc_serve.py`** — pbc 采集链的多批次合并、PDF 回填、文档修复、失败恢复、批量运行、服务模式组件。

**`supp_ingest.py`**（298 行）— 补充法规数据摄取。将四源未收录的补充法规文件组装为 `data/raw/supplementary_regulations.json`。本批次 4 份：F9/F11 来自 nfra.gov.cn 官网全文；F15/F17 来自本地 PDF OCR。流程：读取 `_sources/` 官网全文与人工校对文本 → 本地 PDF 复制到 `downloaded_docs/`（6.4 标准命名）→ 组装 4 条记录 → 输出摄取摘要与 OCR 质量/误差声明。官方出处双保险核验规则：官方地址标题确证 + 权威库正文交叉验证。

**`supp_ingest_batch.py`** — supp 批量摄取。被 `run_production_refresh.py --supp-batch` 调用。

**`supp_ingest_local_dir.py`** — 从本地目录摄取 supp 文件（免网络）。

**`supp_parser.py` / `supp_normalize.py` / `supp_ocr_pdf.py` / `supp_extract_doc_text.py` / `supp_mapper.py` / `supp_sanitize.py` / `supp_downloader.py` / `supp_fix_raw_factual.py`** — supp 采集链的解析、归一、PDF OCR、文档文本抽取、字段映射、清洗、下载、事实修复组件。

### 1.3 采集层共享工具

**`std_lib/scraper_std/crawler_common.py`**（355 行）— 四源共享加固工具层。统一提供：反爬加固 HTTP 客户端（UA 轮换、富请求头、随机延时、指数退避、尊重 Retry-After）；魔数纠正的安全文件名；多格式文档文本抽取（PDF / docx / xlsx / 旧 .xls / 旧 .doc）；日期/全角数字归一、内容哈希、乱码比例检测。设计原则：优雅降级（缺失第三方库时标记 `extract_status="library_missing"`）；透明标记（扫描件/损坏/加密等不可抽情形均返回结构化状态）；零硬依赖（第三方库惰性导入）。关键常量：`USER_AGENTS`（5 个桌面浏览器 UA）、`BASE_HEADERS`（不含 br 压缩）、`_NO_RETRY_STATUS = frozenset({403, 404, 410})`、`_RETRY_STATUS = frozenset({429, 500, 502, 503, 504})`。

**`std_lib/scraper_std/http.py`**（153 行）— 反爬加固 HTTP 客户端。动态轮换 UA 池（PC + 移动端）；自适应请求频率控制（命中 429/503 自动降速，尊重 Retry-After）；指数退避重试（≥3 次）；403/404/410 确定性错误立即返回；代理池开关；流式下载（连接 10s / 读取 30s）；`with` 上下文管理器保证连接释放。

**`std_lib/scraper_std/encoding.py`**（53 行）— 编码自动检测与转换。决策链：显式 hint → chardet 置信度 > 0.9 → 误报规避（拉丁系 + 中文 → gb18030）→ 降级链 gb18030 → utf-8。输出统一 UTF-8 with BOM。

**`std_lib/scraper_std/checkpoint.py`**（59 行）— 断点续抓与优雅退出。信号量捕获（SIGINT/SIGTERM）→ 优雅退出；断点续抓；`GracefulRunner` 上下文管理器。Checkpoint 结构：`{schema, project, updated_at, done_urls, failed_urls, page_count}`。

**`std_lib/scraper_std/circuit_breaker.py`** — 关键锚点元素检测 + 熔断（5.72 KB）。锚点连续 3 次未找到 → 立即熔断：暂停爬虫、告警、输出当前页面 HTML 快照至 `logs/fail_snapshots/`。不允许在未更新选择器的情况下强制跳过或填充空值。关键类：`AnchorDetector`、`Fuse`。

- **watermark**：每阶段 rc==0 后登记「产物水位」（产物版本 + 其所依赖的上游版本），把阶段表里的隐式时序约束变成机器可读的依赖边；`gate_watermark` 据此判定「上游已推进、下游未重跑」
