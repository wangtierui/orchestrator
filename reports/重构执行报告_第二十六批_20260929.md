## 二、变更摘要

### ① pgvector **完整部署达成**（指示①）

**环境实况**：PostgreSQL **18.6** 已装且服务 `postgresql-x64-18` Running；
**但** `pg_config`/`psql` 不在 PATH（安装于 `D:\Program Files (x86)\PostgreSQL\18\bin`），
且**配置端口为 `7777`**（非默认 5432 —— 这正是首轮"连接被拒"的真因）。

**路径选择（三条路逐一排除后只剩一条）**：

| 路径 | 结果 |
|---|---|
| 本地编译（官方 `Makefile.win`） | ❌ **本机无任何编译器**（nmake / cl / cmake / make / gcc 全无） |
| 官方预编译 | ❌ pgvector 官方 **releases = 0**（无资产） |
| Docker 镜像 | ❌ 见 §②（镜像源不可达） |
| **GitHub 第三方 Windows 预编译** | ✅ **走通**：`andreiramani/pgvector_pgsql_windows` → **`vector.v0.8.6-pg18.zip`**（165.8KB，**pg18 精确匹配**） |

**部署与验证**：
1. 下载（GitHub 可达）→ 解压 → 安装 **47 个文件**：`lib/vector.dll`、`share/extension/vector--*.sql` + `vector.control`、`include/.../vector/*.h`；
2. `CREATE EXTENSION vector` → **`vector 0.8.6`** ✓
3. **端到端冒烟**：建 `vector(3)` 表 + 插 3 行 + `ORDER BY emb <-> '[1,0,0]'`
   → 返回 **`1,3,2`**（最近邻正确）；距离 **`0.1414`** = √(0.01+0.01) **精确吻合** ✓
4. Python 客户端：`psycopg 3.3.6` + `pgvector 0.5.0`（pypi）已装 ✓

**⚠️ 认证处置（最小可逆，已复核还原）**：PG 认证为 `scram-sha-256` 且口令未知 →
备份 `pg_hba.conf` → **仅将回环两行**（`127.0.0.1/32`、`::1/128`）临时改 `trust` →
`pg_ctl reload`（**非 restart**，不影响既有连接与数据）→ 建扩展与验证 → **立即还原备份并 reload**。
**复核**：当前文件哈希 **== 备份哈希**、`trust` 行数 **0**、无口令连接 **rc=2**（口令认证已恢复）✓

**登记**：清单 `pgvector.feasibility` 记录路径/验证/认证处置/端点（**`127.0.0.1:7777`，非默认端口**）；
`sqlite_vec` 明确**保留**为"无服务依赖的备选/降级路径"（与既有 FTS5 同库同源）。

### ② docreader **重试定案：仍不可部署**（指示②）

**daemon 确已修复**（`client=29.8.1 server=29.8.1 linux` ✓）—— 但重试暴露**镜像源侧的独立限制**：

| 尝试 | 结果 |
|---|---|
| `docker pull …/library/alpine` | ❌ **blob 阶段 `EOF`**（`image-mirror.r2.daocloud.vip` 不可达；manifest 能取、blob 取不到） |
| `docker pull …/tencentweknora/docreader` | ❌ **白名单明确拒绝**：『**这镜像不在白名单**』（DaoCloud 公共镜像局限） |

⇒ **daemon 已修好，但镜像源双重受限** → 仍不可部署（**非本机配置问题**）。
**解除路径**：① 使镜像 blob CDN 可达；② 或为该镜像申请白名单；③ 或**他处 `docker save` 导出 tar → 本机 `docker load`（离线导入）**。

### ③ 途中即时发现并修复

1. **PG 端口非默认（7777）** —— 首轮"连接被拒"被误判为"服务未监听"，实为**端口不符**；
   经读 `postgresql.conf` 定位（`port = 7777`、`listen_addresses = '*'`）后才连上。
2. **纠正上批"镜像站不可达"的判断** —— 上批以 `URLError` 概括；本轮细分发现国内镜像返回的是
   **`HTTPError`（TCP 连通、仅未认证）**，即**部分可达**；真正的阻塞在 **blob CDN 与白名单**两层。
   本次已按细粒度结论重测（alpine + WeKnora 实拉）后定案。
3. 首轮 pgvector 脚本以 `text=True` 读中文输出触发 **GBK 解码异常** → 改为显式 `encoding='utf-8'`。
