## 六、过程中的返工与教训（如实记录）

| 事件 | 根因 | 现在怎么防 |
|---|---|---|
| 大段替换**误删 `async function render()`** | 用「到下一个 `function` 为止」做边界，跨过了多个函数 | 改为按函数名用**括号配对**定位；删完立即 `typeof` 校验 |
| 表头**错位插入**（把「数据元」列名插到了图谱边表） | 按「文件出现顺序」对应，而两处顺序不同 | 改为按**所属函数**对应；插完逐页 CDP 核对列名 |
| 全量测试出现 **7 个假失败** | 一边跑测试一边 `git pull --rebase`，rebase 逐提交 checkout，文件处于中间态 | 纪律：**测试与 git 写操作不并发** |
| 待办「处置」点了没反应 | 网格行是 `div`，`closest("tr")` 永远返回 `null` | 选择器写成 `closest("tr") || closest(".lv-row")` |
| EAST 表格变「纵向」 | 只把表头转成网格，数据行仍是 `<tr>/<td>`（`<tr>` 在 `<div>` 里被浏览器拆散） | 行构造一并转换；`grep` 断言 `<tr>` 只在 `lvRender` 内 |
| HTML 里 `<span class="lv-cell" class="mono">` 重复 class | 批量正则转换的副作用 | 本轮已统一合并，后续转换后加一次属性检查 |
