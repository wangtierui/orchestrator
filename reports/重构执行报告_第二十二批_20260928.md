## 二、变更摘要

### ① 遗留①：互证分档（零人工）—— 418 行的"内在证据"分层

**方法**（不引入新数据源，纯位置结构）：对每一行"仅窗口命中"记录两个量 ——
`hit_off`（命中条号距**引用起点**的字符距离）与 `rivals`（该条号**之后**是否还有别的候选条号）。

**实测（418 行）**：

| 档位 | 行数 | 判读 |
|---|---|---|
| **强证据**（`hit_off ≤ 40` 且 `rivals = 0`） | **84** | 条号紧邻引用名、全窗无竞争者 → 最像目标条款 |
| 弱证据 | 334 | 其中：40–80 字符 285、**>80 字符 49** |

### ② 遗留②：宽度决议 —— **保持后向 100 字符**（证据驱动结案）

**关键反问**：`>80` 的 49 行是否"距离太远＝可疑"？**抽样证实：不是**。

> 实测：`off > 80` 的 49 行中 **43 行（88%）** 的引用前段含 ≥2 个《》= **长引用列表**。
> 例：`依据《民法典》《基本医疗卫生与健康促进法》《科学技术进步法》《生物安全法》《人类遗传资源管理条例》等，制定` → 条号 `第二条` 必然偏远。

**决议**：
- **不收窄**（会丢掉长引用列表下**合法**的命中）；
- **不加宽**（无正确性增益，只会引入更远的似是而非）；
- 保留 `snippet_window=200`（后向 100），并把**距离分布 + 强/弱分档**登记为**基准披露指标**（供未来人工抽样聚焦：`>80` 的 49 行是**最该先看**的样本）。

### ③ 遗留③：服务型连通性三态（N-113）

此前服务型工具只探"客户端库是否安装"，于是 `offline_ready=None`（"无需外部权重"）与
"**服务未部署**"**混为一谈** —— 用户看到"可用"却连不上服务。
现将 `host:port` 形态端点做**短超时（0.3s）TCP 探测**：
`service_reachable` = True 可连通 / False 不可达（并给出"客户端可用但服务不可达"的 detail）/
None 非服务型或端点非 `host:port`（如 ParadeDB 的 DSN）。

### ④ 遗留④：`--preflight` 启用前置自检（W4）

"P1 未启用"此前只是一个**口头状态**（写在报告里），无人能机器判定"现在能不能启用"。
现固化为**五道闸**（**全过才可启用**，rc 反映结论）：

| 闸 | 内容 | 当前 |
|---|---|---|
| `deps` | 分句增强层至少一个后端可用（hanlp/ltp） | **否**（均未装） |
| `offline` | 已装后端须离线就绪（防首用联网拉权重） | 可 |
| `fp` | 指纹可计算且结构完整（产物 provenance 带得动） | 可 |
| `baseline` | 存在评测基线（v2 否决线："**无度量不得上线**"） | 可 |
| `license` | 许可 `pending` 清空 | **否**（10 项待核） |

→ 实测输出 `P1 启用前置自检：**不可启用**`，rc=1。**把"抢跑"与"遗忘"两类失败同时挡住**
（后者有历史先例：链外产物 N-46 滞后 19 天无人察觉）。

### ⑤ 遗留⑤：许可核验**登记化**（W5）

原文只有各条目的 `license_to_verify: true` **自由标记** → 既答不出"还剩几项"，也**不能当闸门**。
现增清单级 `license_registry`（`verified` 字典 / `pending` 列表 + 入库前置说明），
判据 U 做**三向校验**：① 每个工具须在登记中；② 登记不得含未定义工具（拼写漂移）；
③ verified 与 pending **不得交叠**。判据 U 的 detail 亦披露 `license_pending` 与 `preflight_ok`。

## 三、规范对齐

| 规范 | 落实 |
|---|---|
| 度量先行 | ① 先分档再谈"是否可信"；② 先抽样再决定"改宽/收窄"——**避免无证据调参** |
| 不重复造轮子 | 分档复用 `dst_article_candidates`（公共原语）；preflight 复用 `probe/fingerprint` |
| 唯一事实源 | 许可状态**唯一**于 `license_registry`；启用条件**唯一**于 `preflight()` |
| 数据一致性 | 本轮**未改产物**（全部为披露 + 闸门），定位指标与上一批**逐值一致** |
| 统一调度 | 无新增步骤；分档/归因随既有 `gen_benchmark` 每轮刷新 |
| 元数据管理 | 许可从"自由标记"升为**结构化登记**；启用状态从"报告陈述"升为**可执行自检** |
| 数据处理节点入链 | 无新增节点（判定/披露性质） |
