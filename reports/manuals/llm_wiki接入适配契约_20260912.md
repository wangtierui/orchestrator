# llm_wiki 接入与上游适配契约（2026-09-12）

> 上游：`github.com/nashsu/llm_wiki`（GPL v3，跨平台桌面应用，Karpathy LLM Wiki 模式）
> 本机状态：**已安装 v0.6.11**（2026-08-25，per-user：`%LOCALAPPDATA%\LLM Wiki\llm-wiki.exe`；含 mcp-server/pdfium）
> 定位：知识层（wiki 化 + 语义检索 + 图谱 + 源监控）——**不承载权威字段**（对应《双底座优化与知识库融入架构方案》§2.2/§6）

---

## 一、耦合面（本项目 ↔ llm_wiki，仅两处）

| # | 接口 | 我方实现 | 稳定性 |
|---|---|---|---|
| 1 | **`raw/sources/` 文件协议**（md + YAML frontmatter；SHA256 增量） | `tools/sync_wiki_sources.py`（新增/更新/**--prune**；RFN/IPN 命名 + 截断声明） | 高（文件即协议） |
| 2 | **本地 HTTP API**（`http://127.0.0.1:19828`，Token 鉴权，可选启用） | 预留（检索回供 `/search`、重扫 `/sources/rescan`、图谱 `/graph`） | 中（端点随上游演进） |

**设计原则**：本项目只做**单向喂入 +（可选）只读调用**；wiki 结论回链经 frontmatter `sources[]` 溯源到 RFN/IPN，权威字段以底座发布件为准。

## 二、安装与首次接入步骤

**已完成（2026-09-12）**：
- ✅ 安装 v0.6.11（静默 `/S`，退出码 0；`llm-wiki.exe` + 开始菜单 + 内置 mcp-server）
- ✅ 我方准备：`sync_wiki_sources.py`（可指向项目 `raw/sources/`）、上游监测工具、Obsidian 路径（同源 md 亦可直接看）

**用户侧首次三步**（需人工，涉及 LLM Key）：
1. 打开 LLM Wiki → **创建项目**（模板：通用；建议名"监管合规知识库"）→ 设置 → 配置 **LLM 提供商（API Key）**；
2. 设置 → 开启 **source 文件夹自动监听**（或直接使用项目 `raw/sources/` 路径）；
3. 我方喂数据（**建议先小批**，控 token）：
   ```bash
   python tools/sync_wiki_sources.py --out "<项目路径>\raw\sources" --scope internal          # 内部 957
   # 观察摄取质量后再全量：
   python tools/sync_wiki_sources.py --out "<项目路径>\raw\sources" --scope all [--prune]
   ```

## 三、上游更新 → 本项目适配判定（**回答"是否会同步更新适配"**）

**事实**：上游为独立项目（v0.6.x 系列约**每周一版**），**不会自动同步**到本项目；
但**适配面被刻意收窄为"文件协议"**，因此：

| 上游变更级别 | 对项目影响 | 动作 |
|---|---|---|
| **0.6.x 小版本**（常规迭代） | **零适配**（`raw/sources` 文件协议与命名未变即兼容） | 仅跑监测确认 |
| **大版本**（协议/API 变更） | 需核对 **3 个适配点** | 按下节清单人工核对 |

**适配点核对清单（升级时 4 步）**：
1. **文件协议**：`raw/sources` 是否仍"md + frontmatter + SHA256 增量"？（若变化 → 改 `sync_wiki_sources.py` 单点）
2. **HTTP API**：端口 19828/端点（`/search` `/graph` `/sources/rescan`）/鉴权方式是否变化？（用于后续检索回供接入）
3. **安装形态**：Windows 资产名（setup.exe/portable/msi）是否变化？（仅影响安装说明）
4. 复核后更新**本契约文档**与 `reports/llm_wiki_upstream_state.json` 基线。

**监测机制（已落地）**：
```bash
python tools/check_llm_wiki_upstream.py            # 查询并对比基线（发现新版本会提示核对本清单）
python tools/check_llm_wiki_upstream.py --record   # 核对完成后登记新基线
```
- 已登记基线：**v0.6.11**（2026-08-25）；
