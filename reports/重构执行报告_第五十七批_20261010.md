```

Get-CimInstance：PID 8392 START=14:07:56  CMD="…\WPS Office\…\et.exe" "D:\Desktop\…（用户桌面文件）.xlsx"
⇒ 父进程已退出、打开的是**用户桌面文件** ⇒ **不是我们驱动用户 WPS** ✗（排除）
```

**均已 `RCO_ALLOW_OFFICE_COM` 门禁** ✓；未门禁的两处在 **`refactor/`（非本链）** ⇒ 登记 **W-AF**。

## 三、修复

1. **共享隐藏进程助手**（新增 `std_lib/scraper_std/proc.py`）：`hidden_kwargs()` / `run()` / `popen()` /
   `install_global_defaults()`（Windows：`CREATE_NO_WINDOW` + `STARTF_USESHOWWINDOW`+`SW_HIDE`；调用方显式参数优先；
   置 `RCO_ALLOW_VISIBLE_SUBPROCESS=1` 可关闭）。
2. **全局默认在唯一引导点安装**（`bootstrap.py` 末尾 `_install_hidden_subprocess_defaults()`）⇒
   **一处生效覆盖全仓 54 处调用**（含第三方库发起的子进程）✓。
3. **W-AB**：`doc_convert` 补正式模块 logger（因该文件无 `import logging` 历史，用 `__import__("logging").getLogger(__name__)`
   取得同一对象，规避 `E402 module level import not at top`；已注明选择理由）。
4. **W-Z**：新增 `_extract_docx_lenient()`（直读 `word/document.xml` 提取 `<w:t>`），并在 **`docx` 分支**
   当 python-docx 结果为空时自动回退 ⇒ 修复"缺附属部件即整体失败"（实证受影响：《道路机动车辆生产企业及产品》系列）。
5. **U5 W-Y 未落地**（如实记录）：`nfra_attachments_extract` / `pbc_parse` 中**未找到预期的 `extract_xlsx` /
   `extract_xls_text` 定义形态**（自动锚点 0 命中，未强行改写以免破坏）⇒ 登记 **W-AE**（需人工定位其实际入口名/位置）。
6. **U6 W-V**：未改码。依据：近三次 CI（含与采集并发）**pytest 全绿** ⇒ 该失败为**偶发环境态**（断言依赖磁盘/策略状态）；
   改法已定（发现范围排除 `backups/` 或显式分类），登记待评估。
