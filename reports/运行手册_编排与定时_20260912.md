## 一、编排主链（唯一编排 = `tools/run_production_refresh.py`）

```
阶段 0   抓取（--collect gov,mof,nfra,pbc,supp / nfra-weekly）
阶段 1   clean 五源（run_clean_pipeline --project <src>；尾部自动 clause + clean_index 重建）
阶段 2   时效回写（consolidate --use-state → apply_timeliness_to_cleaned 五源；含 status 派生）
阶段 2.5 classify --all（主题底座/明细/upper 强序重建，断点幂等）
阶段 3   reconcile_clean_drift --apply（RFN↔clean 漂移）
阶段 4   recall（clean/validity/contract/schema 四门禁；FAIL → rc=1）
阶段 4.2 internal merged（内部制度 × RFN 引用视图）
阶段 4.5 reports（全景/主题分类报告）
阶段 5.5 base publish（双底座发布件 + SQLite/FTS5；Base Contract v1）
阶段 6   gates（13 道交付门禁）
阶段 6.5 变更监听基线（cli.py source diff --record → data/watch_baseline.jsonl）（F-O02）
阶段 6.8 分析交付库刷新（cli.py analysis gen → docs/reports/ 15 项）（F-L01；classify 成功亦自动触发，--no-analysis 可跳过）
```

常用入口：

```bash
python tools/run_production_refresh.py --no-scrape          # 日常：raw 已抓取，仅重清洗+全链
python tools/run_production_refresh.py --collect all        # 全量抓取（长时，分段跑）
python tools/run_production_refresh.py --collect nfra-weekly  # nfra 周度增量链（F-O04）
python tools/run_production_refresh.py --no-scrape --supp-batch <backlog.json>  # 含 supp 摄取
```

## 二、定时任务清单（建议调度）

| 频率 | 时间 | 命令 | 说明 |
|---|---|---|---|
| **每周二 01:00** | — | `nfra_weekly.py`（或 `refresh --collect nfra-weekly`）| nfra 周报增量链（单实例锁/顶部窗口/续跑）|
| **每日 06:30** | — | `refresh --no-scrape` | 全链刷新（若当日无 raw 变化则各阶段快跳）|
| **每周一 07:00** | — | `cli.py timeliness verify`（有 Token 时）| 效力缺失核验批次（断点续跑，配额自动停）|
| **核验后** | — | `cli.py timeliness sync` | 台账 → 归属表时效同步（F-C03）|
| **每周一 08:00** | — | `cli.py base publish` + `tools/sync_wiki_sources.py --out <wiki 监控夹>` | 发布件刷新 + llm_wiki 源同步（SHA256 增量）|
| **每月 1 日** | — | `cli.py gates` + `cli.py source diff` + `cli.py timeliness summary` + `tools/check_llm_wiki_upstream.py` | 月度巡检（门禁/快照变更/核验告警/llm_wiki 上游版本）|

## 三、日常巡检与查询

```bash
python cli.py source diff                     # 快照变更监听（F-O02：日期/记录数/内容 sha）
python cli.py source list                     # 源清单与 collector 就绪度
python cli.py base query --rfn RFN-xxx        # 发布件精确查询（Base Contract v1）
python cli.py base search "银行代理保险"      # 全文检索（FTS5 trigram）
python cli.py base query --chain <文号>       # 同文号版本链（F-K08）
python cli.py base query --view active        # 现行有效视图
python cli.py rfn lookup --docno <文号>       # 归属表查询（含部分键回退）
python cli.py rfn register --theme T1 --title "..." # 登记（唯一写口）
python cli.py internal merged                  # 内部制度引用视图
```

## 四、告警与状态接点（rc 语义表）

| 入口 | rc/信号 | 含义 |
|---|---|---|
| `run_production_refresh.py` | rc=2 + `summary.failed` | 任一步失败（含 clean 尾部固定节点 rc=3）|
| `run_retrieval_after_checks.py` | rc=1 | 四门禁任一 FAIL（F-S01；报告见 `recall_audit/output/重跑执行报告.json`）|
| `cli.py gates` | rc=1 | 13 道门禁任一 FAIL（含空跑门禁改 FAIL 后，未实检≠通过）|
| 核验覆盖率门禁 | detail.warnings | < 0.70 拦截（当前 2975/4043=0.7358，未覆盖清单透明化）|
| `cli.py timeliness summary` | — | verify_summary 最近结论（overall/各源缺失）|
| `source diff` | — | 快照变更信号（同日改写可见）|
