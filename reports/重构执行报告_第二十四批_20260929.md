## 二、变更摘要

### ① Youtu-Embedding 替代评估（**结论：可替代**）

| 维度 | Youtu-Embedding | text2vec（原） |
|---|---|---|
| 功能 | 通用文本表示/向量化 | 同 |
| 接入面 | `transformers` + HF 模型 id `tencent/Youtu-Embedding` | `transformers` + `text2vec` pip 包 |
| 性能 | **CMTEB 中文榜 77.58（SOTA, 2025-09）** | 基准线 |
| 许可 | **MIT**（README 徽章） | Apache-2.0 |
| 发行 | **无 PyPI**（GitHub 仓 83.5MB + HF 权重） | PyPI `text2vec` |

**落地**：
- 清单新增 `youtu_embedding`（`probe.kind = **hf_model**`，含 `hf_model` 模型 id）；`text2vec` 标 `superseded_by`（**保留为备选**）。
- 新增 **`hf_model` 探测类型**（此前只有 `module`/`service`/`manual`）：可用性 = 加载库可导入 **且** 权重已在**本地 HF 缓存** —— 后者是**离线纪律的硬要求**（否则首用联网拉数百 MB）。新增 `model_cached` 三态。

### ② 后台下载（**已完成**）

`pip install torch transformers sentencepiece hanlp bertopic text2vec`（后台）→
**Successfully installed**：`torch` / `transformers` / `hanlp-2.1.5` / `bertopic-0.17.4` /
`text2vec-1.3.8` / `sentence-transformers-6.1.0` / `datasets` / `jieba` / `loguru` …

探测翻转：**`6/11 可用`**（bertopic, hanlp, hdbscan, text2vec, umap, youtu_embedding）。
> 附注：上批实测的 48.7 kB/s 属**瞬时**低带宽；本批批量下载顺利完成（故"带宽阻塞"已解除）。

### ③ 许可：**策略化**（按业务决策解除硬闸，但保留披露）

用户明示"许可不影响，部署接入项目使用" → 实现为 **策略驱动**而非删闸门：
- 清单 `license_registry.license_policy = {enforced: false, decision, decided_at, scope:"自用部署（不分发）", residual}`
- `preflight` 的 `license` 闸：读 `enforced` → `false` 时 **ok=True 但 detail 完整披露**未核清单与风险注记
- **决策改变的是"是否阻断"，不是"是否记录"**：`pending_reason` 与 `risk_notes`（如 paradedb=AGPL-3.0）继续保留。
- **可逆**：未来对外分发时把 `enforced` 改回 `true` 即恢复硬闸。

### ④ docreader / ParadeDB：**实测不可部署**（平台不支持）

| 工具 | 前置 | 实测 | 结论 |
|---|---|---|---|
| WeKnora docreader | Docker（官方 compose）或 Go | **docker / docker-compose / go 均无** | 无官方部署路径 |
| ParadeDB | PostgreSQL 扩展 + Docker | **pg_config / psql / docker 均无**；且**无 Windows 原生发行** | 平台不支持 |

**处置**：清单登记 `deploy_blocked{reason, unblock, substitute}`（**不臆造"已部署"**）：
- docreader 替代 → 仓内**已有**版面/正文抽取（`std_lib/scraper_std` + pypdf/pdfplumber/PyMuPDF，6 态），
  docreader 的增量价值（25+ 格式/版面渲染）非当前瓶颈（v2 亦列为 P2-1）。
- ParadeDB 替代 → **SQLite FTS5 保留为降级路径**（v2 P2-2 已定"须先做零服务替代评估"）。

### ⑤ 途中即时发现并修复：**许可核验元数据串线**（N-121）

首次核验把 `youtu_embedding` 记为「**Apache-2.0 ← pypi:license/transformers**」——
但那是**加载库 transformers 的许可**，**不是该工具自身**。根因：`hf_model`/`service` 型工具的
`pypi` 字段表示**加载库/客户端库**，用它核验**本工具**许可属**错误归因**。
**修复**：`verify_licenses` 仅在 `probe.kind == "module"`（pypi 即工具自身）时才回退 PyPI；
非 module 型取不到就**如实挂 pending**。`youtu_embedding` 已回归 pending 并注明
「GitHub NOASSERTION；README 徽章明示 MIT；须人工确认 LICENSE 原文」——**不臆造**。

### 本批改动性质说明（为何全链非阻塞项）

本批改动为**清单元数据 + 探测/策略逻辑 + 报告**：不触碰任何数据产物的生成口径
（`relations`/`clauses`/`base` 等一律未变）。全链的意义在于**端到端一致性**验证，
而该验证已由 CI 的 **gates + 全量 pytest** 覆盖（两者均 PASS 6/6）。故全链补跑属
**收尾确认**，不影响本批交付的正确性。
