## 4. 字段命名审计（专题2）

### 4.1 直接用中文作字段编码（无英文名）的文件
归属/主题归属/rfn 索引/指纹/明细前 10 列/桥前 8 列/recall 各 csv 表头/cleaned `_raw_fields` 内嵌中文键（检索途径/补充途径…）/base·final·upper JSON 混入中文键 `监管文件编号`、值含中文枚举（subtheme=T0上位法锚点）。**CSV 系以中文列名为正式编码，JSON 底座系用英文键 + 个别中文键**，两系需契约桥接。

### 4.2 同义多称谓（节选主集合）
| 语义 | 称谓集合 | 权威/契约 |
|---|---|---|
| 源标识 | source / 文件来源 / file_src / lib / source_origin(值 scraper_nfra) / source_mark / source_id | SOURCE_SET + SOURCE_ALIAS_EQUIV（contract） |
| 文号 | document_number / 发文字号 / doc_no / docno / document_no / index_no | FIELD_SEMANTIC_EQUIV[document_number] |
| 标题 | title / 文件名称 / 标题(明细) | FIELD_SEMANTIC_EQUIV[title] |
| 时效 | timeliness_status / 时效状态 / eff_status / status(verify) / new_status(台账) | TIMELINESS_STATUS(7)；bridge 最近状态=ok/drift_c2 **不同语义同名** |
| 主题 | 主题(全名 T8机构准入…) / primary_theme(T1码) / subtheme(T0上位法锚点) / dst_theme(纯数字"9") | THEME_MAP（码↔全名，第三种纯数字为漂移） |
| 子主题 | cluster / 子主题 / subtheme | cluster |
| 去重键 | dedup_key(sha256) / 唯一键(DOC:) / 文件指纹(MD5) | 三键语义不同均当去重键；`文件指纹.csv` 表头(6列含唯一键)与 `registry.FP_FIELDS`(5列)漂移 |
| 匹配 | matched_by docno_sig(merged) vs docno(reconcile) | REF_MATCH_METHOD / BRIDGE_RELATION |
| 时间戳 | 判定日期/最近确认日期/登记时间/generated_at/finalized_at/last_checked_at/changed_at/…（5+称谓） | `%Y-%m-%d %H:%M:%S` |

### 4.3 高风险项
- `_t1_matched/citerefs` 顶层键=seq 数字串 ≠ 其余主题 RFN；Gate4 `_MATCHED_KEYS` 期望（值含 监管文件编号）与 match 实际输出不符、`_verify_written` 第三套口径——键 schema 三处各表，无单一契约。
- 时效状态与桥同步状态共用"最近状态/状态"列名、值域不同。
