## 二、配置（怎么被识别的）

### 2.1 新增 `local_dir` 探测类型（清单 SSOT）

原探测只有 `module`/`service`/`manual`/`hf_model` 四类，其中 `hf_model` **假设 HF 缓存布局**
（`$HF_HOME/hub/models--org--name`）。本次权重是 **`local_dir` 平铺形态** → 沿用旧口径会把
"权重明明在项目里"判为**未预置**（假阴性）。故新增：

```json
"probe": {"kind": "local_model", "import_name": "sentence_transformers",
          "local_dir": "external/models/bge-base-zh-v1.5",
          "expect_files": ["config.json", "modules.json"]}
```
判据：**目录存在 + `expect_files` 齐备**；`offline_ready` **以目录实检为准**。

### 2.2 新增统一加载层 `std_lib/common_lib/semantic_models.py`

分工固定：**探测归 `semantic_tools`（唯一事实源 = 清单），加载归 `semantic_models`**；
顶层**不导入任何 ML 库**（零硬依赖），失败抛 `ModelUnavailable`（带原因 + 处置），**不吞错**。

| 接口 | 说明 |
|---|---|
| `load_embedder(name).encode(list[str])` | 嵌入（bge / text2vec / youtu） |
| `load_segmenter('ltp').cws/.pos/.split` | 分词 / 词性 / 切句 |
| `embedder_fingerprint(name)` | `{model, dep_version, weights}` → 供产物 provenance |

**离线硬保证**：加载前强制 `HF_HUB_OFFLINE=1` / `TRANSFORMERS_OFFLINE=1` + 显式本地路径
（`local_files_only=True`）→ **不可能首用联网下载**（比"设个 env"更硬）。

### 2.3 新增冒烟工具 `tools/smoke_semantic_models.py`

`probe` 只能证明"依赖装了 + 目录在"，**不能证明能加载能调用**。本工具做**真实初始化 + 真实调用**，
产出可核验证据（维度/样例/耗时/离线开关）。用法：`python -m tools.smoke_semantic_models [name…]`。

## 四、⚠️ 途中发现并处置的问题（**含方案前期未识别项**）

| 编号 | 问题 | 处置 |
|---|---|---|
| **N-157** | `preflight.offline` 闸要求"**所有已装后端**都离线就绪" → 与清单自身声明**矛盾**（`ltp` 条目明写"与 hanlp **二选一**"），把"选了 ltp、未预置 hanlp"判为不可启用 | 改为**按职责分组、每组至少一个就绪**：嵌入三选一 / 分句二选一 → 五闸全过 |
| **N-158** | `MTL_HANLP_OFFLINE` **在 HanLP 官方资料中不存在**（真实开关 `HANLP_OFFLINE`）→ 设了是**假绿灯** | 清单 `offline_env` 更正为 `["HANLP_HOME","HANLP_OFFLINE"]`；并把"防联网"改为**由加载层强制**（env 只作可选） |
| **N-159** | 清单写 `ltp.purpose = "中文分句…（sent_split 专用接口）"`，但**LTP 4.2.14 全包（含 `legacy.py`）无任何分句 API**（`supported_tasks` 仅 cws/pos/ner/dep/sdp/srl/sdpg） | `.split()` 实现为**「LTP 分词 + 句末标点聚合」**，并以 `basis_split` **显式标注非原生分句**；`purpose`/`capability_note` 更正 |
| **N-160** | `youtu_embedding` 的 `modeling_youtu.py` 按 **transformers 4.x** 编写，而环境是 **5.17**（ST 6.1 硬性要求 `>=5,<6`，**不可降级**）→ 逐一暴露 4 处不兼容 | 加载层 `_patch_transformers_compat()` 补 **4 个语义等价垫片**（见 §五），**全项实测通过** |
| **N-161** | 垫片自身引入回归：`pruned_heads` 只读 property 使 **ElectraConfig（LTP 用）设值失败** | 补 **setter**；并核对 `modeling_youtu.py` 依赖的 **21 个符号**中 5.17 **仅缺 1 个**（`LossKwargs`），据此**只补确缺项**，不做无差别打补丁 |
| — | 权重目录非 HF 缓存布局 | 见 §2.1（新增 `local_dir` 类型） |
| — | 上轮 CI `pytest` 600s 超时 | 定位为**与后台模型冒烟进程 CPU 争用**（非代码缺陷）；无争用时 **106.8s** 正常 |

### 兼容垫片清单（`_patch_transformers_compat`，**只在缺失时注入**）

1. `BertTokenizer.batch_encode_plus` —— v5 移除，**ltp 4.2.x** 仍在调（委托 `__call__`）
2. `transformers.utils.LossKwargs` —— v5 移除的**类型标记**（补 `total=False` TypedDict）
3. `ROPE_INIT_FUNCTIONS["default"]` —— v5 键集不含 `default`（按 4.x 语义**重建标准 RoPE**）
4. `PretrainedConfig.pruned_heads` —— v5 移除的属性（补**可读写** property）

> 纪律：**先实测再补**；冒烟工具会把"垫片是否仍生效"变成**可复跑的检查**（未来 transformers 再变会立刻暴露，非静默）。
