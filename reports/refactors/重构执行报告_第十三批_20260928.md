## 三、典型发现（类型收敛暴露的**结构性**问题）

| 形态 | 位置 | 含义 |
|---|---|---|
| **tri-state 全局**（`None`=未加载 / `False`=加载失败 / `callable`=可用） | `supp_ingest._REGISTER_DOC` | 三态挤在单一名字里，类型系统无法表达 → 显式豁免并留注释（后续可改 `Enum`） |
| **同一变量承担"错误累计"与"文件句柄"** | `mof_attachments.last_err`（`None` → 具体异常类型） | 首值 `None` 定死类型 → 标注 `Exception \| None` 还原真实契约 |
| **可空字段裸 `= None`** | `fs_lock.WinFileLock._fh` | 字段被定型为 `None` → 连赋值与非空成员访问**双错**；标注 `IO[str] \| None` 后 `acquire()` 内的收窄恢复 |
| **反复重算同一匹配**（同一行两次 `RE.match`） | `gate_contract` / `build_clause_graph` / `recall_audit` | 第二次调用被 mypy 视为可能 `None`；改 **walrus** 既消错又**少一次匹配**（微性能+可读性） |
| **stub 严于运行时** | `HTTPError(url, code, msg, None, None)` | 运行时接受 `None`，typeshed 要求 `Message` → 显式 ignore 并注明理由（不改运行时行为） |

## 六、遗留风险

1. **约 50 处 `# type: ignore`**：均为**已识别模式**（stdlib/PyMuPDF stub 限制、三态赋值、降级桩、双路径导入），逐条带理由；工具强制 message 过滤。
2. **异质容器的"值域 Any"**：多数修复采用**裸泛型**（`dict`/`list` → 值 `Any`），属"结构正确、精度有限"；
   若要精确表达（如 `detail` 的 `stale_sources: list[str]` 而 `index_stale: bool`），需引入 `TypedDict`——后续按热点模块渐进。
3. **tri-state 与"None 哨兵"模式**未重构（仅标注/豁免）：`supp_ingest._REGISTER_DOC`、各 collector 的 `_n/_a/_u` 降级桩；
   彻底治理需改 `Enum`/`Protocol`，属行为级改造，本轮不做。
4. **`Any` 在 `effective_annotation` 层面的残留**：`check_untyped_defs` 只检查函数体**内部**一致性，
   不强制"为每个形参补注解"；若要"消灭隐式 `Any`"，需再启用 `disallow_untyped_defs`（预计新增大量报错，须单独评估）。
5. **`retention --apply` 仍为人工闸门**（设计如此）：链内只有只读披露；未做"自动归档"。
6. **`tools/` 未被调度的脚本**（第十一批判定）本轮仅做类型收敛，**调度归属未变**（本轮新纳入 `retention`）。
