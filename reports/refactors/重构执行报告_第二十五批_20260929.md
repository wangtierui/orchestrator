## 二、变更摘要

### ① 环境复核（决定性，决定了后续全部路径）

| 检查项 | 实测 | 含义 |
|---|---|---|
| Docker CLI | ✅ 29.8.1 已装 | — |
| **Docker daemon** | ❌ `Docker Desktop is unable to start` | **引擎不可用** |
| `registry-1.docker.io` | ❌ ConnectTimeout | **镜像站不可达** |
| `huggingface.co` / `hf-mirror.com` / `modelscope.cn` / `file.hankcs.com` | ❌ 全部 FAIL | **模型站全不可达** |
| `github.com` / `pypi.org` | ✅ OK | **白名单：仅 github + pypi** |
| PostgreSQL（`pg_config`/`psql`/`postgres`） | ❌ 全无 | **无 PG 宿主** |

> **一句话**：本环境的可达面是 **pypi + github**；**权重、镜像、PG 全在可达面之外**。
> 这条边界解释了本轮三个"不可部署"，也决定了正确做法是**换一个在可达面之内的等价物**。

### ② Youtu-Embedding：**替换已落地，权重不可得**

- **替换落地**（清单层面，唯一事实源）：
  - `youtu_embedding` 已登记为 **P1-1/P1-2 的首选**（`probe.kind = hf_model`，模型 id `tencent/Youtu-Embedding`）；
  - `text2vec` 标 `superseded_by: youtu_embedding`（**保留为备选**，不作首选）。
- **权重不可得（硬边界）**：
  - GitHub 仓库 **releases = 0**（无资产）；根目录仅有 `test_transformers_local.py` / `usage/` 等 →
    证实**权重不在 GitHub**（在 HF Hub，而 HF 不可达）。
  - ⇒ **代码级接入已完成，权重需在可达环境预置后迁入**（`HF_HOME` 指向本地目录）。
  - **不得**因此判定"接入失败"：**库与权重是两件事**（`transformers` 已装、探测 recognize `hf_model` 类型）。

### ③ pgvector：**方向可行、本环境不可部署 → 以 `sqlite-vec` 落地**

| 维度 | 结论 |
|---|---|
| **方向** | ✅ **正确且优于 ParadeDB** —— pgvector 在 PG 生态内更轻（无额外服务层）、23k★、活跃（pushed 2026-09-28）、**免 AGPL 传染**（直接消除原 ParadeDB 的主要合规风险） |
| **阻塞** | ❌ **宿主级三重缺失**：① PostgreSQL 未安装（pgvector 是 PG 扩展，**无宿主即无从编译**）；② Docker daemon 无法启动；③ 镜像站不可达（拉不到 `pgvector/pgvector` 镜像） |
| **落地** | ✅ **`sqlite-vec 0.1.9` 已实际部署**（pypi 可达，win_amd64 wheel 292KB） |

**为何 `sqlite-vec` 是正确的替代（而非降级）**：
1. 与仓内**既有 SQLite FTS5 降级路径同源** —— 同一 SQLite 文件库同时承载**全文与向量**，
   避免引入第二个存储引擎（呼应"不重复造轮子 / 数据一致性"）；
2. **零服务依赖**，完全契合 v2 P2-2 原文『**须先做零服务替代评估**』的纪律；
3. 使向量能力**不依赖任何可达性受限的资源**（模型站/镜像站）——**索引构建与权重解耦**。

### ④ docreader：**双重阻塞**（复检后仍不可部署）

- ① daemon 无法启动；② 镜像站不可达 → **拉不到 WeKnora 镜像**。**非配置问题**。
- 替代：仓内**已有**版面/正文抽取（`std_lib/scraper_std` + pypdf/pdfplumber/PyMuPDF，6 态）；
  docreader 的增量价值（25+ 格式/版面渲染）非当前瓶颈（v2 列 P2-1）。
- **解除路径**：修复 Docker Desktop **且** 镜像可达（或 `docker load` 离线镜像 tar）。

### ⑤ ⚠️ 勘误：Youtu-Embedding 许可**不是 MIT**

读 LICENSE 原文（18 行）：
> 「Tencent is pleased to support the open source community by making Youtu-Embedding available.
> Copyright (C) 2025 Tencent. All rights reserved. **Youtu-Embedding is licensed under the
> License Terms of Youtu-Embedding.**」

⇒ **腾讯自定义条款，非任何标准 SPDX**；**README 徽章标称 MIT 与 LICENSE 原文不一致**。
依"以原文为准"原则：**不得登记为 MIT**（已更正第二十四批报告中"许可 MIT"的记载），
自定义条款的授权范围（商用/分发/衍生）须法务判定 → 保持 pending。
