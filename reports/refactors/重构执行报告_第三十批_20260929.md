### ① A2 · 九类缺陷**机器化审计**（本批核心）

新增 `tools/audit_health.py`（经 `bootstrap` 引导，**只读、可复跑、不静默**）：

| 类别 | 判据要点 |
|---|---|
| 统一入口 | `STEP_ORDER` 声明 vs `_run` 实装（**含 f-string 循环生成**）；`tools/` 脚本未入链；triggers 差异 |
| 门禁失效 | **以 `gates.ALL_GATES` 注册表为准**核验"写了不跑/跑了不存在"；`except: pass` 静默；跳过开关 |
| 数据源不唯一 | 关键标识符在 >2 文件**以字面量出现**（应经 `paths`/`enums` 单一出口） |
| 硬编码 | 绝对路径（**排除检测该问题的门禁自身**）；日期字面量**区分领域字面量与时间语义写死** |
| 实现重复 | 函数体**去注释/去 docstring 后指纹**相同 |
| 代码冗余 | 公共函数全仓零引用（**引用面含 `tests/`**；按**词边界**计数而非"调用形态"） |
| 数据阻塞/效率 | **仅报秒级字面量** `time.sleep(≥1)`；全链耗时 Top5 |
| 流程断点 | 契约常量"仅定义处出现"（引用面含 tests + `contract_manifest.json`） |
| **README 一致性** | 门禁数声明 vs `len(ALL_GATES)`；引用路径是否存在；env 是否有代码/配置出处 |

## 三、⚠️ 审计器**自身误报**的五次纠正（**避免"修错东西"**）

审计器若误报，会让人去修**不存在的问题**——危害不亚于漏报。本批逐一纠正：

| # | 误报 | 根因 | 修正 |
|---|---|---|---|
| 1 | **13 个门禁"未挂载"** | 按"模块名是否在 cli.py 出现"判定，**注册表 `gates/__init__.py` 未纳入核对** | 改为**读 `ALL_GATES` 注册表**（唯一事实源）→ 实测 22=22 完整 |
| 2 | **11 处 `except: pass`** | 判据把"函数体只含**表达式语句**"也算静默（`not body` 中已过滤 Expr）→ `problems.append(...)` 被误判 | 仅 **`pass`/空体**才静默 → 11 处**全为误报**（实际都有实体处理） |
| 3 | **3 个 `{src}` 步骤"声明未实装"** | 正则不匹配 **f-string 步骤名**（`_run(f"collect:{src}", …)` 循环生成） | 正则兼容 `f"…"` + 过滤占位名 |
| 4 | **`artifact_shape` 9 函数"零引用"** | 按**调用形态** `name(` 计数 → **多行 `from x import (\n a,\n b,\n)` 的裸名字不是调用** | 改按**词边界出现次数**（导入/属性/调用一并计入）→ 该模块实由 `gate_contract`/`recall_audit` 消费 |
| 5 | **`code冗余` 72→29、`数据阻塞` 50→6、`硬编码` 55→50** | ① 引用面未含 `tests/`；② 把合法退避/轮询当"固定等待"；③ 把**检测绝对路径的门禁自身**当违规；④ 未区分**领域日期字面量**与**时间语义写死** | 逐条收紧判据（详见审计器内注） |
